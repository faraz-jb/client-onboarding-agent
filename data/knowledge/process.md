# AI Invention — Onboarding Process

Six steps from first contact to a live, supported system.

## 1. Intake & Discovery Call

You tell us what you need. We run a discovery call to understand the actual
process, the tools already in play, and what success looks like.

## 2. Scope Confirmation + Quote

We write the scope down and send a quote against it. Nothing gets built until
you confirm the scope — that document is what the build is measured against.

## 3. Build

We build it. Typical build window is 3-7 days depending on the service.

## 4. Review + Revisions

You review the built system and we run revisions. Two free revision rounds are
included.

## 5. Launch + Training

We launch it and train your team on how to run it day to day.

## 6. Ongoing Support

$49/mo covers ongoing support: maintenance and minor updates. New features
outside the original scope are quoted separately.

## Timelines — how long does it take?

Typical build time per service:

- AI chatbot: 3-5 days
- AI automation workflow: 5-7 days
- Website design: 5-7 days

Timelines start from scope confirmation, not from the first enquiry.
